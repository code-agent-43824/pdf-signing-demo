### Принятые решения и вопросы владельцу

- [x] P2-8, решение Кирилла от 2026-09-29: оставить текущий порядок.
  При выборе браузер проверяет размер и заголовок PDF; после подтверждения
  сервер точно определяет шифрование и отклоняет неподдерживаемый файл **до**
  обращения к токену и создания подписи. Ранний PDF-парсер в браузере и
  отправку файла на сервер до подтверждения не добавлять. Это принятое
  ограничение времени предупреждения, а не недоделанная проверка подписи.
- [x] P1-6, query у `/pdf-signing`: по решению Кирилла от 2026-09-29
  параметры сохраняются при редиректе на `/pdf-signing/`; список допустимых
  имён параметров не нужен. Живой Caddy 2.6.2 обновлён вручную: GET/HEAD
  с query и без него — 308, оба host приводят к странице с исходным query.
  Приложение, readiness, статика и соседний сайт проверены после reload.
